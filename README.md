# CLIMATERIA · 气候万象志

### 一部关于气候与文明的地图册


*万物有灵，气候亦然。*


## 📖 初心

**我们相信，气候是有灵魂的。**

每一片雨林、每一粒沙、每一阵季风，在漫长的地质时间中，都已沉淀出独特的“性格”。它们是地球的呼吸，是时间的刻痕，是文明的摇篮。

但地图上那些冰冷的色块和数字，从未讲述过它们真正的故事。

**CLIMATERIA** 诞生于这样一个想法：**如果气候会说话，它们会如何描述自己？** 如果我们不再将气候视为“资源”或“数据”，而是视为有记忆、有性格、有使命的存在——世界会有什么不同？

这不是一套科普工具，而是一次**通感的实验**。我们用文学赋予气候以人格，用地理赋予人格以根基，用交互赋予根基以生命。我们邀请用户像翻阅一部古老的手稿一样，去感受气候与文明之间那些被忽视的、沉默的联系。

> 每一个气候区域，都是一位灵性存在。
> 每一段故事，都是一部微缩的地球史诗。


## 🎯 目的

**CLIMATERIA** 希望通过一次“沉浸式阅读”，完成三件事：

1. **让气候被感知**  
   将抽象的气候数据转化为可触摸的“灵性存在”——有名字、有性格、有故事、有使命。让用户不再从外部“观看”气候，而是与气候“相遇”。

2. **让地理被记住**  
   每一段灵性叙事，都建立在真实的地理知识之上。我们不跳过数据，也不淹没在数据中——我们用故事承载知识，让用户在阅读传说时，不自觉地记住大气环流、洋流、纬度、海拔——那些构成地球骨架的“沉默的语法”。

3. **让文明被回望**  
   气候从未超然于人类文明之外。它塑造了我们的语言、信仰、节日、饮食、建筑、生存方式。每一个角色的命名、每一种意象的选取、每一段彩蛋的埋设，都是对人类文明与自然之间那条模糊边界的轻声回响。

## ⚙️ 功能

### 1. 首页 · 卷轴摊开
三段式叙事动画，以“传说”的方式进入这个世界。不可跳过，不可速览——它是一次仪式，而非一个入口。

### 2. 万象图 · 灵性探索
- 27个发光圆点，悬浮于真实的世界气候分布图之上
- 悬停 → 底部牛皮卷轴浮现角色信息
- 点击 → 右侧展开人物详情卡片

### 3. 人物详情卡片 · 四折经折装
- 左图右史：人物画像 + 灵性档案
- 四折结构：灵性 · 灵力 · 血脉 · 图鉴
- 每一折都是故事，每一折都是知识
- 地理知识直接对应高考考点，不架空、不绕路

### 4. 九州志 · 中国气候版图
> *即将到来。*
- 中国气候五灵：顾澜 · 林和音 · 陆云峥 · 沈寒川 · 江铮
- 以中国版图为底图，五方气候区域金线勾勒
- 交互方式与万象图一致：悬停预览 · 点击阅读

### 5. 谱系 · 家族血脉图谱
> *即将到来。*
- 9大家族的完整亲缘关系树
- 从大地之母到每一位气候之灵的完整血脉链路
- 家族信物 · 家族格言 · 年度家族事件
- 视觉呈现：横向长卷 + 纵向族谱，如古籍中的“世系图”

### 6. 罗盘 · 温度带星盘
> *即将到来。*
- 多层同心圆结构：热带族 · 亚热带族 · 温带族 · 寒带族 · 高山族
- 以星盘/罗盘的视觉语言呈现温度带的垂直与水平秩序
- 点击任一角色 → 跳转至万象图对应详情

### 7. 问灵 · 气候剧场
> *即将到来。*
- 不同气候之灵之间的对话剧场
- 跨家族叙事：雨林姐妹与沙漠兄弟的相遇、季风与西风的对话
- 角色在特定情境下的“灵言”与“回应”
- 形式：类似戏剧剧本或手稿对话录，用户可翻阅不同“幕次”

### 8. 视觉体系 · 东西方融合
- 羊皮纸底图 + 金箔贴边 + 朱砂印章
- 中式工笔重彩 + 西方古典版画
- 古星图 × 金碧山水 × 矿物色 × 金线蚀刻
- 画面具有**神性光辉**与**传世感**

## 🚀 快速开始

1. 将两份参考图与 `index.html` 置于同一目录
2. 将人物画像放入 `images/characters/` 目录
3. 用浏览器打开 `index.html`
4. 等待首页三段式叙事动画结束
5. 点击「展开图卷」进入万象图
6. 悬停圆点探索，点击圆点阅读详情
